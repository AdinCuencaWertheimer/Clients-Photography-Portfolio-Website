# Photography Portfolio Website for Client

**Live Site:** shotsbyilan.com

##  Overview
**Shots by Ilan** is a  photography portfolio website I designed and developed for a photographer.

I was hired to build the full website from scratch, handling everything from layout design and responsive styling to deployment and custom domain setup. The final result is a professional .com site that serves as a personal brand hub for the photographer.

---

##  Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript**
- **Netlify**
- **VS Code**
- **GitHub**

##  What I Learned
- Real-world web deployment workflow from local → GitHub → Netlify  
- Setting up and managing a **custom .com domain** with DNS and HTTPS  
- Writing maintainable, modular front-end code  
- Building professional client-facing websites under real project expectations  
- Balancing performance, design, and responsiveness for creative portfolios
